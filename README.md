# 기후정원연구소 GitHub Pages 홈페이지

기후정원연구소(Climate Garden Lab)용 정적 홈페이지 기본 템플릿입니다.

## 파일 구성

- `index.html` : 홈페이지 본문
- `style.css` : 디자인 및 반응형 스타일
- `script.js` : 모바일 메뉴 및 연도 표시

## GitHub Pages에 올리는 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 `index.html`, `style.css`, `script.js` 파일을 Repository 최상위에 업로드합니다.
3. Repository의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, Folder를 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 GitHub Pages 주소가 생성됩니다.

## 수정이 필요한 항목

- 이메일 주소
- 전화번호
- 회사/연구소 주소
- 실제 제품 이미지
- 프로젝트 실적 및 사진
- 로고
- 회사명/법인명 표기
